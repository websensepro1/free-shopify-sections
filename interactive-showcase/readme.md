# Interactive Showcase Section

An interactive tabbed showcase for your Shopify store: circular icon tabs with an animated timer ring, a large synced display image, and a content panel with title, description and button.

## Overview

Visitors click (or let autoplay cycle through) the circular tabs. Each tab switches the big image and the content panel together, while a progress ring around the active circle shows how long until the next tab. Ideal for product categories, self-care routines, feature highlights or service overviews.

## Features

- Circular icon tabs inside a rounded pill bar
- Animated timer ring with optional autoplay loop (3–15 seconds per tab)
- Big display image that syncs with the active tab
- Title, description and button per tab
- Upload your own circle image/icon, or use the built-in default SVG icons
- Horizontally scrollable tab bar on small screens, active tab auto-centers
- Theme editor friendly: selecting a block previews its tab
- Customizable colors, max width and top/bottom padding
- Fully responsive for all screen sizes
- Compatible with any Shopify 2.0 theme, no paid app required

## Getting Started

1. In your Shopify admin go to **Online Store → Themes → ⋯ → Edit code**.
2. Under **Sections**, click **Add a new section** and name it `interactive-showcase`.
3. Paste the contents of `interactive-showcase.liquid` and click **Save**.
4. Go to **Customize**, click **+ Add section** and choose **Interactive Showcase**.
5. Add **Feature Item** blocks and fill in each tab's content.

## Customization

**Section settings**
- Heading and subheading
- Enable/disable autoplay and set the timer speed
- Maximum width and top/bottom padding
- Colors: background, heading/label, description, tabs bar, timer ring, button, button hover

**Feature Item block**
- Circle icon label
- Circle small image/icon (optional, falls back to a default icon)
- Big main display image
- Content title and description
- Button text and link
